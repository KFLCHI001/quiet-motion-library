# Source and publication record

The interaction research began with a user-supplied recording of Apple Health's State of Mind flow. That recording contains private phone content. The recording, frames, screenshots, artwork, copy, local storyboard, local orb code, and local exports are **not** in this repository. The public source cited for factual comparison is [Apple's State of Mind guide](https://support.apple.com/en-euro/guide/iphone/iph6a6decb13/27/ios/27). Apple describes a mood/emotion slider followed by optional word and impact choices. This library is independent and is not affiliated with or endorsed by Apple.

| Comparison | Public Apple reference | This example |
| --- | --- | --- |
| Purpose and copy | Log a state of mind, then optionally name feelings and impacts | Adjust an unnamed numeric signal; one screen, no logging or health language |
| Primary art | Large layered contour form around the selected feeling in the local reference study | Eleven separate, angled rectangular tiles crossing a straight rail |
| Color and space | Multicolored mood treatment in the local reference study | Off-white field with brick and copper tiles and dark green rail |
| Continuity | A selected form persists through later questions | A three-tile motif is available to the host; no staged question flow |
| Input behavior | Slider changes the visual state | Generic 0–1 host value changes tile height, tilt, and color |

The shared mechanic is continuous input affecting visual parameters. Geometry, composition, palette, copy, and purpose were authored anew. We compared the rendered public example against the local, private source-study storyboard and checked the public Apple guide for the documented flow. This table records that side-by-side check. No Apple media is redistributed.
