# Verification record

Copy this block next to the motion source. Write "not run" rather than leaving a field blank or implying a check.

```markdown
## <cue name>

- Interaction: <screen, user action or value, true state reflected>
- Meaning limit: <what this motion does not claim>
- Sources and rights: <original / licensed / reference only; license and attribution>
- Workflow and settings: <tools and versions, exact parameters, prompts if any>
- Cost: <spend and plan tier, or "none">
- Editable source: <path to the layered or model source>
- Outputs and sizes: <path — bytes, for each exported file>
- Static fallback: <path; when it is shown>
- Reduce Motion: <behavior>
- Interruption, undo, background: <behavior>
- Tested in browser: <runtime and version, what was observed — or "not run">
- Tested natively: <renderer, build type, device and OS, what was observed — or "not run">
- Accessibility check: <screen reader and result — or "not run">
- Open items: <anything not yet verified>
```
